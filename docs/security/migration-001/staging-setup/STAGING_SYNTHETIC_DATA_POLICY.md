# Staging synthetic-data policy

Permitted future data: synthetic users, manufacturer and retailer users, approved vendor records, test memberships and invitations, fake CRM records, non-sensitive sample products, and placeholder media. Generate any stable identifiers specifically for staging.

Prohibited: production Auth users, real customer data, real emails or phone numbers, recordings, CRM conversations, private manufacturer documents, payment data, production Storage objects, API secrets, service-role keys, and production OAuth credentials.

No data was seeded during this task.
