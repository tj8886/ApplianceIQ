The US UP application previously tried direct customer, CRM and Spec IQ writes that are restricted in the migrated database. It also used floor profile IDs as CRM user owners. Zero linked records was an observed symptom, not proof of when each imported record failed.

The authenticated up_crm_handoff operation checks the active mapped actor, organization membership, store access and customer scope. Floor records retain profile IDs; CRM/Spec IQ ownership uses source user IDs. Logging from the kiosk or standard walk-in form creates the waiting record, interests, contact, deal, project, draft and integration link in one transaction. Stable waiting IDs and row/advisory locks prevent duplicate retries. Requested/assigned rep IDs are checked against active organization membership. Rep assignment updates the CRM owner. Sale outcomes and follow-ups update the linked deal. Failed handoffs roll back and are shown to the user rather than silently ignored.

This is a narrow private SECURITY DEFINER workflow with explicit authorization, a fixed empty search path, revoked public/anonymous/service execution and an invoker API wrapper. Direct table write privileges remain unchanged. User-entered interest prices remain quotes; no verified catalog prices, consent or specs are invented. Empty draft totals are unknown, and no product specifications are fabricated.

Validation uses rollback-only fixtures for authenticated linkage, retry identity, active-shift assignment, sale outcome, foreign organization/unmapped identity rejection and failed-write rollback. Client tests cover both generated page syntax and RPC/error handling. All 11 generated US app bundles pass routing and preserved auth checks. No test customer persists, no notifications are sent and no historical walk-ins are backfilled by these tests.

Limits: this does not certify every rotation, clock-in, floor metric, notification, or signed-in browser workflow. Imported historical customers are retained. An actual signed-in customer interaction remains the final user-facing acceptance check.
